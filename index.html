# tools

  • prgate →

    Um workflow para Github Action que alerta usuários quando um pull request modifica arquivos protegidos como linters, testes e CI workflows. É postado um comentários simples listando os arquivos modificados e pode adicionar um bloqueio até as necessárias aprovações. É uma ferramenta totalmente determinística, e agnóstica a linguagens de programação, útil para prevenir mudanças causadas por IA sem supervisão humana.
