# tools

  • prgate →

    A GitHub Action that flags when a pull request touches “protected” files — tests, lint configs, CI workflows. It posts a single sticky comment listing the matched files and can block merges until an approval label is applied. Fully deterministic, language-agnostic, zero AI in the check itself.
